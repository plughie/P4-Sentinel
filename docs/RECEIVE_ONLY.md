# Receive-only behavior

P4 Sentinel does not transmit. The RTL-SDR path is receive-only, and the RF
Monitor does not record or export audio by default. SD logging is for structured
observation events and captures supported by the selected mode; do not treat it
as a raw RF recorder.

A decoded value is shown with the validation level the implementation supports.
A valid packet or protocol header does not by itself establish a person's
identity, agency, intent, location, or legal status. Do not use the output as a
substitute for direct verification or emergency communications. Follow local
radio, privacy, and recording rules.

The Network Scanner performs passive Wi-Fi/BLE discovery. It does not connect
to access points or transmit probe, impersonation, or disruption traffic.
